## `lib/seccomp.json`

Derived from Docker's default seccomp profile, `seccomp/default.json` from
[moby/profiles](https://github.com/moby/profiles), as vendored in moby/moby at the tag
`docker-v29.9.2`
(`vendor/github.com/moby/profiles/seccomp/default.json`).

- Copyright The Moby Authors. moby/moby's `NOTICE` reads: "Docker. Copyright 2012-2017 Docker,
  Inc. This product includes software developed at Docker, Inc. (https://www.docker.com)."
- License: Apache License 2.0 ([LICENSES/Apache-2.0.txt](LICENSES/Apache-2.0.txt)).

The file is generated by [`scripts/seccomp-profile`](scripts/seccomp-profile), which fetches
Docker's profile for that tag and changes it as follows:

- `socketcall` is removed from Docker's unconditional allow list. Its arguments are out of
  seccomp's sight, so it could open any socket.
- Docker's rule allowing `socket()` for every address family below 38 is replaced by rules
  that allow the same families except `AF_NETLINK` (16), and allow `AF_NETLINK` only for
  protocols other than `NETLINK_NETFILTER` (12). These rules, marked `"comment": "omanywhere:
  ..."`, match the low 32 bits of each argument.
- A rule is added that allows `clone` and `unshare` with no argument check, so processes can
  make namespaces for Chromium's sandbox (marked `"comment": "omanywhere: namespaces, ..."`).

[docs/usage.md](docs/usage.md#the-run-flags) explains why.

## The image

`make image` builds from Arch Linux's official image and installs Arch's and Omarchy's
packages unmodified. Each package keeps its own license, found under `/usr/share/licenses` in
the image. This repository redistributes none of them.

Publishing a built image would add the obligation to offer the source of its GPL packages.
